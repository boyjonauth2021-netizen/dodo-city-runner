Dodo City Runner v4.1

Open index.html over a local web server (run.sh / run.bat, or `python3 -m http.server`).
Needs a modern browser with ES modules.

This build includes the 48 kbps soundtrack in assets/music/. Do not re-encode.
These last tracks are instrumental versions of commercial Mauritian sega/seggae songs —
confirm rights before any public release; they are for private use in this project only.

v4.1: real SRTM mountain heightfields, a brighter lab intro, fairer oncoming traffic,
and a camera that still sits behind the chaser (it only pulls back when the dodo is flying
or on a high rooftop). See README.md and maps/README.md.
